Live-state drift and self-heal
------------------------------
Command used only to introduce deliberate drift:
kubectl -n gitops-demo scale deployment/gitops-app --replicas=5

Immediately after drift:
NAME         DESIRED   READY
gitops-app   5         2

After Argo CD self-heal:
NAME         DESIRED   READY
gitops-app   2         2
Argo CD: Synced / Healthy

Explanation: Git declares two replicas and the Argo Application enables
selfHeal. The manual five-replica live state differed from Git, so Argo CD
automatically restored two replicas. The manual command was used only as a
controlled drift demonstration, not as a repair.
